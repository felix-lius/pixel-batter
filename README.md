# 像素击球手 (Pixel Batter)

一款像素风单机网页弹幕反击游戏。灵感来自《满头大汗了吧，击球手！》（Circle Hitter）的核心机制：在圆形竞技场里躲避弹幕，把来袭的子弹反弹回去击杀敌人。

纯前端**单文件 HTML**，无需联网、无需服务器，双击即玩。

## 特性

- **圆形竞技场**：玩家只能在圆环内移动，自动限制在边界内。
- **躲避 + 反击**：点击把进入攻击范围的来袭子弹反弹出去，反弹弹呈青色、自动飞向最近敌人。
- **体力系统**：每次击球消耗体力；击杀回体、随时间缓慢恢复，体力不足无法击球。
- **生命与护盾**：5 条命，受击 1.2 秒无敌帧防连环暴毙；护盾道具形成防御结界，8 秒内自动反弹所有进入范围的来袭弹。
- **金币与角色**：击杀掉落金币，localStorage 永久保存金币与最高分；含「初心者」（可玩）与「其他模式」（待开发）两个角色。
- **道具系统**：盾（自动反弹）、慢（弹幕减速）、力（体力回满）、命（加 1 条命）。
- **敌人类型**：普通直线弹、散射弹、追踪弹；随时间（波次）提升数量与弹速。
- **计时与计数**：记录本局存活时长与击杀数，结算与首页排行榜展示。
- **历史前三排行榜**：按得分保留历史前三（得分 / 时间 / 杀敌数），存于 localStorage（金币为累计数据，不列入排名）。
- **程序化音效与背景音乐**：用 Web Audio API 实时合成，无任何外部音频文件。

## 操作

- **电脑**：移动鼠标操控击球手，鼠标左键击球反弹。
- **手机（横屏）**：竖屏会提示横屏；横屏后左半屏拖动 = 移动，右半屏点击 / 按住 = 回击。
- 开始页右上角可切换静音；游戏页「体力」读数下方有【返回】键可随时退出。

## 道具说明

| 道具 | 颜色 | 作用 |
|------|------|------|
| 盾 | 青色 | 护盾结界，8 秒内自动反弹来袭弹 |
| 慢 | 紫色 | 弹幕减速 |
| 力 | 绿色 | 体力回满 |
| 命 | 红色 | 加 1 条命 |

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 技术说明

- 纯前端单文件：HTML5 Canvas 渲染 + Web Audio 程序化音频。
- 逻辑分辨率 360×360，配合 CSS `image-rendering: pixelated` 实现像素放大。
- 进度存档使用浏览器 localStorage（最高分 `pb_best`、金币 `pb_coins`、角色 `pb_roles`、静音 `pb_sound`、历史前三 `pb_top3`）。
